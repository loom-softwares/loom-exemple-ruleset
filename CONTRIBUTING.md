# Contributing to Loom Demo System

Thanks for your interest in improving Loom Demo System! This is a community ruleset for [Loom VTT](https://loomvtt.com), and contributions of every size are welcome: bug reports, ideas, translations, documentation and code.

By taking part you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting bugs and requesting features

- Search the [existing issues](https://github.com/loom-softwares/loom-exemple-ruleset/issues) first.
- Open a new issue with clear steps to reproduce (for bugs), the Loom VTT version you use, and screenshots when they help.
- For feature ideas, explain the problem you want to solve before the solution you have in mind.

## Sending changes

1. Fork the repository and create a branch from `main`.
2. Keep each pull request focused on one change.
3. If your change adds visible text, add the keys to every language file in `lang/`.
4. Run the project's checks when they exist (for example `npm test`) before opening the pull request.
5. Open the pull request and describe what changed and why.

We use [Conventional Commits](https://www.conventionalcommits.org) for commit messages (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`).
